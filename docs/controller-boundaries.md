# Controller boundaries

The factory enforces the following properties with regression tests:

1. Project installations, tests, builds and independent acceptance execute in isolated offline containers.
2. Publication uses deterministic connector calls, exact argument validation and durable receipts, without a model turn.
3. Fresh pilot tasks start from a versioned unsolved fixture; solved tasks spend no coding attempt.
4. Every post-spawn persistence or log failure terminates and reaps the child process.
5. A durable precommit checkpoint makes finalization resumable after ledger/API outages without another agent turn.
6. Service signals require full process identity, start time, group leader and runtime ownership.
7. The pilot validates exact package URL, graph and SHA-512 before installation; verified archives supply the offline cache.
8. Independent CLI acceptance checks both readable default and exact JSON output.
9. Optional Claude preparation creates project, milestone, tickets and handover; startup verifies preparation and personal entitlement.
10. Published commits require exactly one pinned parent and the expected tree; moving bases stop publication.
11. Runtime paths reject Git checkouts, symlink escapes and packaged source before creating credentials.
12. CI success metrics exclude skipped/cancelled runs from the executed denominator and report them separately.
13. Health requires identified daemon and MCP processes plus authenticated API/MCP readiness.

Additional regressions cover host Git hooks/filters, export attributes, agent-controlled nested
Git metadata, pinned permission roots, read isolation, ticket-scoped writes and network denial.

The native Claude crew has a separate permission model and needs independent end-to-end
verification on a colleague's entitled account. The generic onboarding/handoff workflow works
for arbitrary repository profiles; the bounded three-ticket controller remains a synthetic pilot.
Production approval remains separate from build success, human merge and optional Code Owners.
