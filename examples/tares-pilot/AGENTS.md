# Synthetic agent pilot

This is a synthetic standalone exercise. Write access is limited to the task paths.
Read the task and edit only its listed paths. Preserve all existing tests; add useful regression tests.
Run npm run lint, npm test and npm run build in this directory. Network is unavailable to coding agents.
Do not commit, push, merge, release, install tools globally, access credentials, or change Factory controls.
The controller performs independent acceptance checks and prepares the pull request separately.
This is the completed reference. Fresh exercises use the separately versioned baseline.
